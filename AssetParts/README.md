# ملفات اللعبة (Content) مقسّمة

ملفات اللعبة الحقيقية (1580 ملفاً، 3.4 جيجا) مضغوطة ومقسّمة إلى قطع أصغر من 100 ميجا،
لأن رفعها عبر Git LFS رُفض. لاستعادتها بعد تنزيل المستودع:

- ويندوز: `powershell -ExecutionPolicy Bypass -File AssetParts\restore.ps1`
- ماك / لينكس: `./AssetParts/restore.sh`

السكربت يجمع القطع، يتحقق من البصمة SHA-256، ويفك الملفات إلى `PUBG_BP_Project/Content`.
كل ملف أصلي تم التحقق منه قبل الضغط مقابل بصمته في مؤشرات LFS الأصلية.
