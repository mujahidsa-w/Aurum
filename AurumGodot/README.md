# Aurum — Godot 4.7 lobby

لوبي ثلاثي الأبعاد للعبة باتل رويال، مبني على **Godot 4.7** (آخر نسخة مستقرة: 4.7.2).
اللوبي مستوحى من تخطيط لوبيات ألعاب الموبايل، لكن كل التصميم والأسماء والأيقونات أصلية — بدون شعارات أو أصول لألعاب أخرى.

## التشغيل
1. نزّل Godot 4.7.x (النسخة العادية، مش .NET).
2. من مدير المشاريع: **Import** واختر الملف `AurumGodot/project.godot`.
3. اضغط **Run** (F5). المشهد الرئيسي: `scenes/lobby.tscn`.

## الموجود في اللوبي
- مشهد ثلاثي الأبعاد: سماء متحركة بغيوم، شمس وظلال، مبنى برج مراقبة، سيارة باغي، طائرة محطمة، جبال وعليها برج إرسال، أشجار وعشب يتحرك مع الهواء، بركة ماء صغيرة.
- الشخصية في المنتصف (جاكيت بقلنسوة، كمامة، سنيكرز، بندقية) مع حركة تنفس — **اسحب بالماوس/الإصبع لتدويرها**.
- أعلى اليسار: الصورة الرمزية (تُرسم حياً من وجه الشخصية)، الاسم والتاج، المستوى وشريط الخبرة، خانات الفريق 0/10، بانر الفعالية، زر Find Teammates.
- أعلى الوسط: مزامنة سحابية، الإشعارات، المتجر (بدون شعار).
- أعلى اليمين: الذهب والكريدت وزر +، أيقونات الباس/الصناديق/المتجر، بانر Aurum Pass، مربعات Deals و Events.
- أسفل اليسار: بطاقة الطور مع معاينة حية للخريطة، زر **START** (بحث عن مباراة ← MATCH FOUND ← تحميل)، المنطقة والجودة والساعة الحية.
- أسفل اليمين: شات World (رسائل تلقائية + تقدر تكتب)، زر الإيموت، التحميل، وشريط: CLAN | SETTINGS | SEASON | WORKSHOP | MISSIONS | INVENTORY.

اللوبي يفتح **ملء الشاشة** تلقائياً (F11 أو Alt+Enter للتبديل، وفيه خيار في الإعدادات). على الجوال دائماً ملء الشاشة.

كل الأزرار تفتح نوافذ شغالة: اختيار الطور والخريطة والفريق، الإعدادات (الجودة تغيّر الرسوميات فعلياً، FPS، المنطقة)، المخزون (تغيير لون اللبس وسكن السلاح)، المهام مع استلام الجوائز، الصناديق، المتجر، الباس، الشات، الملف الشخصي. خانات الفريق تمتلئ فعلاً لما يقبل اللاعب الدعوة، إنشاء كلان باسم تختاره، تنزيل حزم الموارد، الانضمام للفعاليات، واستلام جائزة الموسم. التقدم يُحفظ تلقائياً.
(العملات والمتجر والتنزيلات محاكاة محلية داخل اللعبة لحد ما يُربط سيرفر.)

## المباراة (Battleground) — جزيرة Vis الحقيقية في كرواتيا
زر START في اللوبي يفتح المباراة:
- **الخريطة:** تضاريس حقيقية من بيانات الارتفاع (18×9 كم)، بحر وسماء حقيقية (HDRI)، مدن Vis وKomiža والقرى في أماكنها الحقيقية، مواقع عسكرية وبنكرات، مطار Plisko Polje، صخور وشجيرات وأشجار صنوبر.
- **الأسلحة (14 سلاح حقيقي):** M1911، USP، MP5، AKM، AK-74M، M4A1، SKS، SVD، G28، قناص .338، VSS، Remington 870، M4 Super 90، M249 — موديلات واقعية بأبعادها الحقيقية، وكل سلاح بعياره وسرعة طلقته ومعدل إطلاقه الحقيقي.
- **إطلاق نار واقعي:** كل رصاصة مقذوف حقيقي (سرعة الفوهة + سقوط بالجاذبية + مقاومة هواء)، ارتداد، تشتت حسب الحركة، تصويب بتكبير حقيقي ومنظار للقناصات، طلقة رأس ×2.3، أنماط إطلاق، تعبئة.
- **الباتل رويال:** نزول بالمظلة من 700م، 23 بوت ذكي يتقاتلون مع بعض ومعك، دائرة تضيق على 6 مراحل، غنائم (أسلحة، ذخيرة، إسعافات)، Kill feed، خريطة مصغرة، بوصلة، وذهب حسب الأداء.
- **التحكم:** كمبيوتر (WASD + الماوس، Shift ركض، C انحناء، Space قفز/مظلة، زر يمين تصويب، R تعبئة، F التقاط، Q تبديل، B نمط، H علاج، Esc قائمة) أو جوال (جويستيك + سحب للنظر + أزرار متعددة اللمس).

الحقوق والتراخيص لكل الموديلات في `CREDITS.md` (رخصة CC-BY تتطلب ذكر الفنانين — لا تحذف الملف).

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `scripts/lobby.gd` | نقطة البداية، يربط العالم والواجهة، تدوير الشخصية بالسحب |
| `scripts/lobby_world.gd` | العالم ثلاثي الأبعاد (السماء، الإضاءة، المباني، العشب، الجبال) |
| `scripts/character_model.gd` | الشخصية والسلاح وحركة الـ idle والإيموت |
| `scripts/lobby_ui.gd` | كل الواجهة والنوافذ والبحث عن مباراة |
| `scripts/game_state.gd` | بيانات اللاعب والحفظ (Autoload باسم `GameState`) |
| `scripts/ui_icons.gd` | الأيقونات والرسومات (SVG تُرسم وقت التشغيل) |
| `scripts/mesh_kit.gd` | أدوات بناء المجسمات |
| `scripts/game/battleground.gd` | إدارة المباراة (اللاعبين، البوتات، الغنائم، النهاية) |
| `scripts/game/vis_world.gd` | جزيرة Vis: التضاريس، البحر، المدن، الطبيعة |
| `scripts/game/weapon_db.gd` | قاعدة الأسلحة ومواصفاتها الحقيقية (إضافة سلاح = سطر + ملف glb) |
| `scripts/game/ballistics.gd` | محاكاة المقذوفات |
| `scripts/game/player.gd` / `bot.gd` / `combatant.gd` | اللاعب، الذكاء الاصطناعي، المنطق المشترك |
| `scripts/game/zone.gd` / `pickup.gd` / `game_hud.gd` | الدائرة، الغنائم، واجهة المباراة |

الموديلات: `models/wooden_crate_1.fbx` (صندوق خشبي) يُحمّل تلقائياً ويتحجّم ويوضع على الأرض، ولو انحذف ترجع صناديق بسيطة بداله.
لإضافة موديل جديد استخدم الدالة `_place_model()` في `lobby_world.gd`.

الخط: Barlow Condensed (رخصة SIL OFL، الملف `fonts/OFL.txt`).

## الموبايل
المشروع مضبوط على الوضع الأفقي، بدقة تصميم 1920×1080 مع تمدد تلقائي للشاشات العريضة،
ويستخدم Forward+ على الكمبيوتر و Mobile renderer على الجوال. من الإعدادات داخل اللعبة اختر
Smooth / Balanced للأجهزة الضعيفة.
