# بناء نسخة أندرويد (ملف APK)

يُبنى على أجهزة Linux في GitHub بمحرك **Unreal Engine 5.8** من المصدر. لا تحتاج أي جهاز.

## التشغيل
1. تأكد من وجود السر `EPIC_GITHUB_TOKEN` في إعدادات المستودع.
2. افتح **Actions ← Android Build (UE5, APK) ← Run workflow**.
3. البناء يجري على **مراحل**: كل مرحلة 6 ساعات كحد أقصى، والتالية تكمل من حيث توقفت السابقة.
4. عند النجاح تجد الملف في **Artifacts** باسم `AurumMobile-Android-Development`.

## التثبيت على الهاتف
- الملف موقّع بمفتاح تجريبي (debug)، فيُثبَّت مباشرة.
- انسخ الـ APK إلى الهاتف وافتحه، ثم اسمح بالتثبيت من مصادر غير معروفة.
- ملفات اللعبة داخل الـ APK نفسه، فلا حاجة لملف OBB منفصل.
- النسخة تحتوي خريطة `Level_Test` فقط. `Level_Battle` مستبعدة لأنها ثقيلة، انظر `Config/Android/AndroidGame.ini`.

## المراحل
| المرحلة | العمل |
|---|---|
| فحص الكود | ترجمة كود اللعبة C++ وحده أولاً، لاكتشاف الأخطاء بسرعة |
| المحرّر | بناء محرر UE5 للينكس، ويلزم لتحويل ملفات اللعبة |
| اللعبة | بناء اللعبة لمعالجات أندرويد arm64 |
| التحويل والحزم | تحويل المحتوى لصيغة ASTC وشيدرات Vulkan/GLES، ثم إنتاج الـ APK |
